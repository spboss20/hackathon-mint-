
SUPPORTIQ CUSTOMER SUPPORT FAQ

1. Payment Issue:
If payment is deducted twice, the support team must verify both transactions before processing a refund.

2. Refund Policy:
Refund requests are reviewed by the support team. Refunds are not automatically approved.

3. Delivery Issue:
If an order is delayed, customers should provide their order ID so the support team can check the delivery status.

4. Account Security:
If a customer suspects unauthorized account access, escalate the issue immediately to the security team.

5. Technical Issue:
For technical problems, ask the customer to describe the error and share relevant details.
